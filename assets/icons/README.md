# Icons

SVG icons used by the UI kit. All icons use `currentColor` — set the color with a core token (`text-high`, `white`, `primary`, …) on the parent element.

| File | Size | Used in |
|---|---|---|
| [`arrow.svg`](arrow.svg) | 20 × 20 | Button trailing arrow (ui-kit 4.2) |
| [`maximize.svg`](maximize.svg) | 16 × 16 | Card icon button — open / read more (ui-kit 4.2) |
| [`code-xml.svg`](code-xml.svg) | 15 × 15 | Neutral tag icon, example «Websites» (ui-kit 4.1) |
