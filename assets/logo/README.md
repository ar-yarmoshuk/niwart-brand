# Logo files

Versions and usage rules are defined in [`00-core-niwart.md`](../../00-core-niwart.md), section 5.

## Naming

`niwart-logo-<version>.<ext>`

| Version | Use on | Files |
|---|---|---|
| `color` | `white`, `bg-subtle` | `niwart-logo-color.svg`, `niwart-logo-color.png` |
| `white` (gradient mark) | `bg-dark` | `niwart-logo-white.svg`, `niwart-logo-white.png` |
| `full-white` | `primary` | `niwart-logo-full-white.svg`, `niwart-logo-full-white.png` |

- SVG is the master file; PNG only for tools that do not accept SVG (export at 2× or larger, transparent background).
- Other variants (icon only, horizontal / vertical lockup) follow the same pattern, e.g. `niwart-icon-color.svg`.
